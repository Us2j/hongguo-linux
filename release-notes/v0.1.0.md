## Hongguo v0.1.0（Linux 桌面学习客户端）

> 仅用于个人学习、逆向研究和本地互操作实验；非官方客户端，不绕过账号 / 会员 / 付费内容。
> 使用前请阅读仓库中的 `NOTICE` 与 README 免责声明。

### 功能
- 推荐流 / 分类（真人剧 · 漫剧 · AI短剧）/ 站内 + 网页搜索
- 1080p：`video_model` 解析、`spade_a` CENC 解密、H.264/HLS 播放
- 竖滑预览、剧集切换、Electron UI

### 安装（用户版）
- **AppImage**：`chmod +x Hongguo-User-*.AppImage && ./Hongguo-User-*.AppImage`
- **deb**：`sudo dpkg -i Hongguo-User-*.deb`
- 用户版内置模拟器身份池、自带轮换；运行需 Java 21、FFmpeg（详见 README）。

### 校验
下载 `SHA256SUMS` 与产物置于同一目录后：

```
sha256sum -c SHA256SUMS
```
